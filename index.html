Vou para a final?

Digite só a média de cada trimestre (a MTRIM do boletim). A média da escola é 8,0: se a média simples dos três trimestres ficar abaixo disso, a matéria vai para a final. Se for para a final, a nota necessária na prova é 12 menos a média anual. Com dois trimestres preenchidos, mostro quanto falta tirar no outro.
